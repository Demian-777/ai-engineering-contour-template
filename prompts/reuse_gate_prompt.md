# Reuse Gate Prompt

Read `AGENTS.md` and the relevant brief.

Assess whether this change should reuse existing code, patterns, platform capabilities, or proven dependencies before building new functionality.

Return:

- Existing assets or patterns that may solve the problem.
- Build-vs-reuse recommendation.
- Dependency recommendation, if any.
- Risks of adding new code or dependencies.
- The smallest justified next step.

Do not assume any application stack or add new tools unless the brief approves them.
