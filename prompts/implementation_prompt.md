# Implementation Prompt

Read `AGENTS.md` and the relevant brief before changing anything.

Implement only one approved step from the brief or plan.

Rules:

- Touch only files listed as allowed.
- Do not edit files listed as forbidden.
- Avoid new dependencies unless explicitly approved.
- Keep the change small, direct, and reversible.
- Do not introduce stack choices or infrastructure outside the approved scope.
- Run the configured checks that apply to the change.
- Summarize the diff, checks run, and any remaining risks.
- Stop for review after the approved step.
