# AI Engineering Contour Template

A lightweight, stack-neutral template for starting AI-assisted engineering projects with a reuse-first, plan-before-code workflow.

This repository does not choose an application stack, package manager, deployment model, database, or AI runtime.

## How to use

1. Copy this template for a new project.
2. Read `AGENTS.md`.
3. Create a change brief from `docs/changes/_template/brief.md`.
4. Use the prompts in `prompts/` when they help with reuse checks, implementation, review, or security review.
5. Replace the placeholder CI workflow with real project checks before relying on CI.

`AGENTS.md` is the authoritative workflow and agent instruction file.
